# R. Siva Koushik — Developer Portfolio

A responsive, static personal portfolio built with HTML, CSS, and JavaScript. Designed for straightforward deployment to Vercel.

## Run locally

No package installation or build step is required.

- Open `index.html` in a browser, or
- Use the VS Code Live Server extension for a local development server.

## Deploy to Vercel

1. Create a new GitHub repository, for example `koushik-portfolio`.
2. Upload/push the contents of this folder to the repository root.
3. Sign in to [Vercel](https://vercel.com/) with GitHub and import the repository.
4. For this static site, leave the framework preset as **Other** and leave the build command empty. Use `./` as the output directory if Vercel asks for one.
5. Deploy, then open the generated URL and test navigation, contact links, and mobile layout.

Vercel deployment requires your own account authorization. Do not share passwords or tokens in chat.

## Before publishing

- Add your actual resume as `resume.pdf` if you want a downloadable resume. The current site intentionally does not show a fake or broken resume download button.
- Add real GitHub repository links to projects when you are ready. No project repository URLs have been assumed.
- Review the project descriptions and status labels for accuracy.

## Updating the site

Edit `index.html`, `assets/css/style.css`, or `assets/js/main.js`, commit and push the changes to the connected GitHub repository. Vercel can automatically redeploy the production branch when Git integration is enabled.
